# Variabel JavaScript

Variabel adalah tempat untuk menyimpan data dalam program.

JavaScript memiliki tiga cara utama untuk mendeklarasikan variabel:

## 1. Menggunakan let

Digunakan ketika nilai variabel dapat berubah.

```javascript
let nama = "Ibnu";

nama = "Fauzi";

console.log(nama);
```

## 2. Menggunakan const

Digunakan ketika variabel tidak akan diberi nilai ulang.

```javascript
const umur = 26;

console.log(umur);
```

## 3. Menggunakan var

Merupakan cara deklarasi variabel pada JavaScript lama.

```javascript
var kota = "Blitar";

console.log(kota);
```

## Kesimpulan

Gunakan `const` sebagai pilihan awal jika nilai tidak perlu diubah, dan `let` jika nilainya perlu berubah.
