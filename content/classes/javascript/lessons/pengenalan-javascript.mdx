# Pengenalan JavaScript

Selamat datang di kelas **Belajar JavaScript**!

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif.

## Apa yang Bisa Dilakukan JavaScript?

Dengan JavaScript, kita dapat:

- Membuat tombol interaktif.
- Memvalidasi formulir.
- Memanipulasi elemen HTML.
- Membuat aplikasi web.

## Contoh Kode JavaScript

```javascript
const nama = "Codelab";

console.log("Selamat belajar di " + nama);
```

Hasil kode tersebut:

```text
Selamat belajar di Codelab
```

Selamat belajar dan jangan takut mencoba!
