## Pengertian Konfigurasi Jaringan

**Konfigurasi jaringan** adalah proses mengatur koneksi jaringan pada komputer atau server agar dapat berkomunikasi dengan perangkat lain melalui jaringan lokal maupun internet. Dalam administrasi server, konfigurasi jaringan diperlukan agar server dapat diakses oleh pengguna dan menjalankan layanan seperti Web Server, DNS Server, dan DHCP Server.

## Komponen Jaringan

Beberapa komponen penting dalam konfigurasi jaringan:

| Komponen          | Fungsi                                       |
| ----------------- | -------------------------------------------- |
| IP Address        | Identitas perangkat dalam jaringan           |
| Subnet Mask       | Menentukan jaringan dan host                 |
| Gateway           | Jalur menuju jaringan lain                   |
| DNS               | Menerjemahkan nama domain menjadi IP Address |
| Network Interface | Antarmuka koneksi jaringan                   |

Untuk melihat informasi routing, gunakan perintah `ip route`:

```bash
root@debian:/home/fauzidleware# ip route
```

Melihat informasi DNS gunakan perintah `cat /etc/resolv.conf`

```bash

```

- enp0s3
- ens33

## Konfigurasi IP Address DHCP

**DHCP** merupakan metode pemberian IP Address secara otomatis dari server DHCP atau router. Pada VirtualBox dengan mode NAT, Debian biasanya mendapatkan IP secara otomatis.

Untuk praktik DHCP akan kita lakukan di materi yang lain.

## Konfigurasi IP Address Static

**IP Static** adalah alamat IP yang ditentukan secara manual oleh administrator. Pada Debian 13 dengan konfigurasi jaringan menggunakan `/etc/network/interfaces` file tersebut dapat di edit menggunakan `nano`.

```bash
root@debian:/home/fauzidleware# nano /etc/network/interfaces
```

Hasilnya seperti ini:

```bash
# This file describes the network interfaces available on your system
# and how to activate them. For more information, see interfaces(5).

source /etc/network/interfaces.d/*

# The loopback network interface
auto lo
iface lo inet loopback

# The primary network interface
allow-hotplug enp0s3
iface enp0s3 inet dhcp
# This is an autoconfigured IPv6 interface
iface enp0s3 inet6 auto
```

Pada **# The primary network interface** ubah isi konfigurasinya seperti ini:

```bash
# This file describes the network interfaces available on your system
# and how to activate them. For more information, see interfaces(5).

source /etc/network/interfaces.d/*

# The loopback network interface
auto lo
iface lo inet loopback

# The primary network interface
auto enp0s3
iface enp0s3 inet static
    address 192.168.1.10/24
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 1.1.1.1

# This is an autoconfigured IPv6 interface
iface enp0s3 inet6 auto
```

Sesuaikan alamat IP, gateway, dan interface dengan jaringan yang digunakan. Jika sudah simpan konfigurasi dengan

- Tekan tombol **Ctrl + O**
- Tekan tombol **Enter** untuk menyimpan file
- Tekan tombol **Ctrl + X** untuk keluar

Setelah itu restart pengaturan dengan perintah:

```bash
root@debian:/home/fauzidleware# systemctl restart networking
```
