## Pengertian APT

**APT (Advanced Package Tool)** adalah sistem manajemen paket pada Debian yang digunakan untuk menginstal, memperbarui, dan menghapus perangkat lunak. Dengan APT, administrator dapat mengelola berbagai aplikasi dan layanan server tanpa harus mengunduh serta memasangnya secara manual.

Contoh perangkat lunak yang dapat diinstal menggunakan APT:

- Apache Web Server
- Nginx
- OpenSSH Server
- MariaDB
- DNS Server (BIND9)
- DHCP Server

## Mengenal Repository Debian

**Repository** adalah tempat penyimpanan paket perangkat lunak yang dapat diunduh dan diinstal oleh sistem Linux. Debian menyediakan repository resmi yang berisi berbagai aplikasi dan pembaruan sistem. Konfigurasi repository dapat diperiksa melalui `cat /etc/apt/sources.list`

```bash
root@debian:/home/fauzidleware/data# cat /etc/apt/sources.list
#deb cdrom:[Debian GNU/Linux 13.7.0 _Trixie_ - Official amd64 NETINST with firmware 20260912-09:35]/ trixie contrib main non-free-firmware

deb http://deb.debian.org/debian/ trixie main non-free-firmware
deb-src http://deb.debian.org/debian/ trixie main non-free-firmware

deb http://security.debian.org/debian-security trixie-security main non-free-firmware
deb-src http://security.debian.org/debian-security trixie-security main non-free-firmware

# trixie-updates, to get updates before a point release is made;
# see https://www.debian.org/doc/manuals/debian-reference/ch02.en.html#_updates_and_backports
deb http://deb.debian.org/debian/ trixie-updates main non-free-firmware
deb-src http://deb.debian.org/debian/ trixie-updates main non-free-firmware

# This system was installed using small removable media
# (e.g. netinst, live or single CD). The matching "deb cdrom"
# entries were disabled at the end of the installation process.
# For information about how to configure apt package sources,
# see the sources.list(5) manual.
```

## Memperbarui Daftar Paket

Sebelum menginstal aplikasi, administrator sebaiknya memperbarui daftar informasi paket. Gunakan perintah `apt update`. Perintah tersebut mengambil informasi paket terbaru dari repository:

