Pada materi sebelumnya, kita telah berhasil menginstal Debian 13 Server menggunakan Oracle VM VirtualBox. Sekarang kita akan mulai belajar mengoperasikan Debian melalui Command Line Interface (CLI). **Terminal** merupakan salah satu alat utama yang digunakan administrator Linux untuk mengelola server. Melalui terminal, kita dapat mengelola file, direktori, pengguna, jaringan, layanan, hingga keamanan sistem.

Pada materi ini, kita akan mempelajari perintah-perintah Linux yang paling sering digunakan dalam administrasi server, mulai dari navigasi direktori, pengelolaan file, membaca informasi sistem, hingga memahami hak akses pengguna.

## Mengenal Terminal Linux

**Terminal** adalah antarmuka berbasis teks yang digunakan untuk berinteraksi dengan sistem operasi melalui perintah-perintah tertentu. Melalui terminal, pengguna dapat menjalankan berbagai instruksi tanpa harus menggunakan antarmuka grafis.

Dalam administrasi server, terminal sangat penting karena sebagian besar konfigurasi dan pengelolaan server Linux dilakukan melalui CLI. Contoh aktivitas yang dapat dilakukan melalui terminal:

- Membuat dan menghapus direktori
- Mengelola file konfigurasi
- Menginstal perangkat lunak
- Mengatur pengguna
- Memeriksa jaringan
- Mengelola layanan server
- Memeriksa kondisi sistem

### Pengertian CLI

**CLI (Command Line Interface)** adalah antarmuka yang memungkinkan pengguna berinteraksi dengan komputer menggunakan perintah teks. Berbeda dengan GUI (Graphical User Interface) yang menggunkan ikon serta tombol, CLI mengandalkan instruksi yang diketik melalui keyboard. Contoh perbandingannya:

| GUI                                     | CLI                               |
| --------------------------------------- | --------------------------------- |
| Menggunakan tampilan grafis             | Menggunakan perintah teks         |
| Berinteraksi melalui mouse dan keyboard | Umumnya menggunakan keyboard      |
| Mudah digunakan pemula                  | Membutuhkan pemahaman perintah    |
| Cocok untuk penggunaan desktop          | Sangat umum digunakan pada server |

### Pengertian Shell

**Shell** adalah program yang bertugas menerima perintah dar pengguna, menerjemahkannya, dan menjalankan instruksi melalui sistem operasi. Salah satu shell yang paling umum digunakan pada Linux adalah **Bash (Bourne Again Shell)**. Contoh perintah menggunakan Bash:

```bash
fauzidleware@debian:~$ echo "Selamat belajar Linux"
Selamat belajar Linux
```

### Hubungan Terminal, Shell, dan Kernel

Ketika komponen ini memiliki fungsi yang berbeda:

- Terminal menjadi tempat pengguna memasukkan perintah
- Shell menerima dan memproses perintah
- Kernel mengelola sumber daya sistem untuk menjalankan instruksi

## Mengenal Prompt Terminal Linux

Ketika berhasil login ke Debian 13, kita akan melihat tampilan terminal yang menunjukkan bahwa sistem siap menerima perintah. Contohnya:

```bash
fauzidleware@debian:~$
```

Tampilan tersebut disebut prompt.

### Bagian-Bagian Prompt

| Bagian       | Fungsi                              |
| ------------ | ----------------------------------- |
| fauzidleware | Username yang sedang digunakan      |
| debian       | Hostname komputer                   |
| ~            | Menunjukkan direktori home pengguna |
| $            | Menunjukkan pengguna biasa          |

Jika menggunakan akun root, biasanya prompt berakhir dengan simbol `#`. Contohnya

```bash
fauzidleware@debian:~$ su -
Kata Sandi:
root@debian:~#
```

Pada contoh di atas saya masuk ke root menggunakan perintah `su -` untuk masuk ke super user, lalu memasukkan kata sandi root dan sekarang status prompt nya berubah menjadi root.

### Menjalankan Perintah

Untuk menjalankan perintah Linux, ketik perintah pada terminal kemudia tekan Enter. Contohnya:

```bash
root@debian:~# whoami
root
root@debian:~# exit
logout
fauzidleware@debian:~$ whoami
fauzidleware
fauzidleware@debian:~$
```

Pada contoh di atas saya lakukan perintah `whoami` ketika berada di root dan user biasa. Perintah `exit` digunakan ketika ingin keluar dari posisi root ke user biasa.

Linux bersifat case sensitif, artinya perintah dengan huruf kecil dan huruf besar dianggap berbeda walaupun baca nya sama. Contohnya:

```bash
fauzidleware@debian:~$ whoami
fauzidleware
fauzidleware@debian:~$ WHOAMI
-bash: WHOAMI: perintah tidak ditemukan
fauzidleware@debian:~$
```

## Perintah Dasar untuk Navigasi Direktori

**Navigasi direktori** adalah kegiatan berpindah dan melihat lokasi dalam sistem Linux.

Contohnya ketika ingin mengetahui lokasi direktori yang sedang aktif bisa menggunakan perintah `pwd` **(Print Working DIrectory)**:

```bash
fauzidleware@debian:~$ pwd
/home/fauzidleware
```

Artinya saat ini sedang berada di direktori **/home/fauzidleware**.

Lalu jika ingin menampilkan daftar file dan direktori, gunakan perintah `ls`

```bash
fauzidleware@debian:~$ ls
```

Jika tidak muncul apa-apa, karena memang pada bawaannya direktori ini terlihat kosong. Coba kita mundur dua direktori ke belakang:

Selanjutnya ada perintah `cd` atau **(Change Directory)** digunakan untuk berpindah direktori. Contohnya berikut untuk berpindah ke direktori home pengguna

```bash
fauzidleware@debian:/$ cd /home/
fauzidleware@debian:/home$
```

Berikut perintah untuk kembali ke direktori sebelumnya:

```bash
fauzidleware@debian:/home$ cd ~
fauzidleware@debian:~$
```

Berikut contoh jika mau naik satu tingkat direktori:

```bash
fauzidleware@debian:~$ cd -
/home
fauzidleware@debian:/home$
```

Dalam Linux, terdapat dua cara untuk menunjukkan lokasi file atau direktori. **Path Absolut** merupakan alamat lengkap yang dimulai dari direktori root `/`. Contohnya:

```bash
fauzidleware@debian:~$ cd /home/fauzidleware/
```

**Path Relatif** merupakan alamat yang dihitung berdasarkan direktori saat ini.. Contohnya jika sedang berada di lokasi **/home**

```bash
fauzidleware@debian:~$ cd ..
fauzidleware@debian:/home$ pwd
/home
```

Langsung jalankan `cd fauzidleware` untuk berpindah ke direktori user nya

```bash
fauzidleware@debian:/home$ cd fauzidleware
fauzidleware@debian:~$ pwd
/home/fauzidleware
```

## Perintah Membuat dan Mengelola Direktori

Perintah `mkdir` \*\*(Make Directory) digunakan untuk membuat direktori baru. Contohnya:

```bash
fauzidleware@debian:~$ pwd
/home/fauzidleware
fauzidleware@debian:~$ mkdir belajar-linux
fauzidleware@debian:~$ ls
belajar-linux
```

Perintah tersebut membuat direktori dengan nama **"belajar-linux**. Untuk membuar beberapa direktori sekaligus:

```bash
fauzidleware@debian:~$ mkdir dokumentasi backup gambar rekaman
fauzidleware@debian:~$ ls
backup  belajar-linux  dokumentasi  gambar  rekaman
```

Untuk membuat direktori bertingkat:

```bash
fauzidleware@debian:~$ mkdir -p proyek/web/assets
fauzidleware@debian:~$ ls
backup  belajar-linux  dokumentasi  gambar  proyek  rekaman
```

Opsi `-p` memungkinkan pembuatan direktori induk yang belum tersedia.

Perintah `rmdir` digunakan untuk menghapus direktori kosong. Contohnya:

```bash
fauzidleware@debian:~$ ls
backup  belajar-linux  dokumentasi  gambar  proyek  rekaman
fauzidleware@debian:~$ rmdir belajar-linux
fauzidleware@debian:~$ ls
backup  dokumentasi  gambar  proyek  rekaman
```

Perintah tersebut hanya berhasil jika direktori tidak memiliki isi.

Perintah `tree` digunakan untuk menampilkan struktur direktori dalam bentuk pohon. Contohnya:

```bash
fauzidleware@debian:~$ tree
-bash: tree: perintah tidak ditemukan
```

## Perintah Membuat dan Mengelola File

Perintah `touch` digunakan untuk membuat file kosong. Contohnya:

```bash
fauzidleware@debian:~$ ls
backup  dokumentasi  gambar  proyek  rekaman
fauzidleware@debian:~$ touch catatan.txt
fauzidleware@debian:~$ ls
backup  catatan.txt  dokumentasi  gambar  proyek  rekaman
```

Perintah tersebut membuat file bernama **"catatan.txt"**. Lalu ada juga perintah `cp` **(Copy)** digunakan untuk menyalin file atau direktori. Berikut contohnya menyalin file:

```bash
fauzidleware@debian:~$ cp catatan.txt catatan-copy.txt
fauzidleware@debian:~$ ls
```

## Perintah Mengedit File

Dalam administrasi server, kita sering perlu mengubah file-file konfigurasi. Salah satu editor yang umum digunakan melalui terminal adalah **Nano**.

**Nano** merupakan editor teks berbasis terminal yang mudah digunakan oleh pemula. Jika belum terpasang instal menggunakan perintah `apt install nano`.

Contohnya gunakan perintah

```bash
fauzidleware@debian:~$ nano catatan.txt
```

Nano akan mengedit file **"catatan.txt"** namun jika belum punya file tersebut maka nano akan membuatkan file baru.

Maka akan terbuka editor seperti berikut ini:

![Ilustrasi JavaScript](/images/debian13/termuk-3.png)

Contoh praktik:

1. Setelah terbuka editor nano untuk file **catatan.txt** seperti di atas
2. Ketik **"Saya sedang belajar Debian 13"**
3. Tekan `Ctrl + O`
4. Lalu tekan `Enter` untuk menyimpan
5. Tekan `Ctrl + X` untuk keluar
6. Jalankan perintah `cat catatan.txt` untuk memeriksa hasilnya

```bash
fauzidleware@debian:~$ cat catatan.txt
Saya sedang belajar Debian 13
```

## Perintah Informasi Sistem

Selain mengelola file, administrator perlu mengetahui kondisi sistem yang sedang berjalan. Contohnya yang sudah pernah kita gunakan untuk menampilkan username yang sedang digunakan menggunaka `whoami`:

```bash
fauzidleware@debian:~$ whoami
fauzidleware
```

Untuk menampilkan nama komputer atau server gunakan perintah `hostname`:

```bash
fauzidleware@debian:~$ hostname
debian
```

Untuk menampilkan informasi tentang kernel Linux bisa gunakan `uname -a` atau `uname -r` kalau mau versi kernelnya saja:

```bash
fauzidleware@debian:~$ uname -a
Linux debian 6.12.115+deb13.1-amd64 #1 SMP PREEMPT_DYNAMIC Debian 6.12.115-2 (2026-11-01) x86_64 GNU/Linux
fauzidleware@debian:~$ uname -r
6.12.115+deb13.1-amd64
```

Untuk menampilkan lama waktu sistem telah berjalan gunakan perintah `uptime`

```bash
fauzidleware@debian:~$ uptime
 19:53:06 up  1:23,  2 users,  load average: 0,00, 0,00, 0,00
```

Untuk menampilkan tanggal dan waktu sistem gunakan perintah `date`

```bash
fauzidleware@debian:~$ date
Sab 07 Nov 2026 19:54:00 WIB
```

```bash
52K     /home/fauzidleware
```

Perintah tersebut menampilkan total penggunaan penyimpanan direktori **/home/fauzidleware**.
