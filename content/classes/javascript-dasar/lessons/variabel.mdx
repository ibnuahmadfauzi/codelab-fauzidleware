Setelah mempelajari materi **Variabel Dalam JavaScript** kita bisa menjelaskan pengertian variabel, memahami fungsi variabel dalam program, menggunakan berbagai jenis variabel, membuat dan mengubah nilai variabel, serta menerapkan variabel dalam program sederhana.

## Pengertian Variabel

**Variabel** adalah tempat untuk menyimpan data sementara yang dapat digunakan kembali selama program berjalan. Semisal dalam sebuah aplikasi kampus kita membutuhkan tempat untuk menyimpan data:

- Nama mahasiswa
- Fakultas mahasiswa
- Jurusan mahasiswa
- NIM mahasiswa

Data-data tersebut dapat disimpan menggunakan variabel.

## Cara Membuat Variabel

JavaScript memiliki tiga kata kunci untuk mendeklarasikan variabel, yaitu `var`, `let`, dan `const`.

### Menggunakan `var`

`var` merupakan cara lama untuk pembuatan variabel. Berikut contoh penggunaannya:

```javascript
var nama = "Ibnu";
console.log(nama);
```

### Menggunakan `let`

`let` digunakan untuk membuat variabel yang nilainya dapat diubah ketika program berjalan. Contohnya:

```javascript
let nama = "Ibnu";
console.log("Nama :" + nama);

nama = "Ibnu Fauzi";
console.log("Nilai Nama Baru : " + nama);
```

### Menggunakan `const`

`const` digunakan untuk membuat variabel yang tidak dapat diberi nilai ulang. Contohnya:

```javascript
const nama = "Ibnu";
console.log("Nama :" + nama);

nama = "Ibnu Fauzi";
console.log("Nilai Nama Baru : " + nama);
```

Dari kode di atas hasilnya jadi seperti ini:

![Ilustrasi JavaScript](/images/javascript/variabel-2.png)

Output yang pertama bisa keluar, tapi saat membaca output yang kedua terjadi error karena memang kata kunci `const` tidak bisa diatur ulang nilainya.

### Perbedaan `var`, `let`, dan `const`

| Kata Kunci | Nilai dapat diubah?      | Cakupan  |
| ---------- | ------------------------ | -------- |
| `var`      | Ya                       | Function |
| `let`      | Ya                       | Block    |
| `const`    | Tidak dapat diatur ulang | Block    |

Dalam penulisan JavaScript modern, sebaiknya menggunakan `let` ketika nilai bisa diubah-ubah dan `const` ketika nilai variabel tidak perlu diatur ulang atau diubah, hindari penggunaan `var`.

### Aturan Penamaan Variabel

Beberapa aturan penamaan variabel:

- Nama variabel tidak boleh diawali angka
- Tidak boleh menggunakan spasi
- Tidak boleh menggunakan kata kunci JavaScript
- Nama variabel membedakan huruf besar dan kecil
- Gunakan nama yang mudah dipahami

Contoh:

```javascript
let nama = "Ibnu";
let nilai = 80;
let status = "Lulus";
```

## Latihan

Masih ingat dengan latihan program menampilkan data mahasiswa pada materi sebelumnya.

![Ilustrasi JavaScript](/images/javascript/pengenalan-javascript-6.png)

Sekarang tugasnya silahkan gunakan variabel untuk menyimpan masing-masing data mahasiswa lalu tampilkan dengan hasil yang sama.

## Hasil Latihan

```javascript
let nama = "Ibnu Ahmad Fauzi";
let jurusan = "Teknik Informatika";
let fakultas = "Teknologi Informasi";
let nim = "19104410028";

console.log("=================================");
console.log("DATA MAHASISWA");
console.log("=================================");
console.log("Nama     : " + nama);
console.log("Jurusan  : " + jurusan);
console.log("Fakultas : " + fakultas);
console.log("NIM      : " + nim);
console.log("=================================");
```
