## Pengertian JavaScript

Jika HTML digunakan untuk membangun struktur dasar halaman web dan CSS digunakan untuk mempercantik tampilan halaman web, **JavaScript** merupakan bahasa pemrograman yang digunakan untuk membuat halaman website menjadi lebih interaktif dan dinamis. Contohnya:

- Menampilkan pesan ketika tombol diklik
- Mengubah teks pada halaman website
- Melakukan perhitungan secara otomatis
- Memvalidasi formulir
- Membuat menu interaktif
- Mengambil dan menampilkan data dari server

## Hubungan HTML, CSS, dan JavaScript

Ketiga teknologi ini memiliki fungsi yang berbeda, namun saling melengkapi satu sama lain.

Seperti yang sudah saya jelaskan sedikit di atas:

- **HTML** atau _HyperText Markup Language_ digunakan untuk membuat struktur halaman web dan bagaimana elemen ditampilkan. Contohnya HTML digunakan untuk membuat sebuah elemen tombol.
- **CSS** atau **Cascading Style Sheets** digunakan untuk mempercantik tampilan web atau memberi style tambahan pada elemen. Contohnya sebelum ini kita sudah membuat tombol polos dengan HTML, dengan bantuan CSS kita bisa membuat tampilan tombol lebih menarik seperti mengubah warna, background, efek bayangan, efek ketika kursor masuk ke dalam tombol, dsb.
- **JavaScript** digunakan untuk menambah interaksi dari elemen-elemen web nya. Contohnya ketika sebuah tombol diklik akan menampilkan aksi seperti muncul pesan popup di halaman web atau memberi aksi seperti mengubah teks yang ada di halaman web.

Dengan JavaScript, kita dapat:

- Membuat tombol interaktif.
- Memvalidasi formulir.
- Memanipulasi elemen HTML.
- Membuat aplikasi web.

## Cara Menjalankan JavaScript

Ada beberapa cara untuk menjalankan JavaScript. Yaitu:

- Langsung menggunakan di **Console** browser yang ada di **Developer Tools**
- Menggunakan skema embed di internal file HTML
- Menggunakan skema eksteral dengan file sendiri yang memiliki ekstensi **.js** lalu memanggil file tersebut ke dalam HTML

### Melalui browser

Browser seperti **Google Chrome** menyediakan **Developer Tools** yang dapat digunakan untuk menjalankan kode JavaScript.

Langkah-langkah:

- Buka Google Chrome
- Tekan tombol `F12`
- Pilih tab Console
- Ketik kode JavaScript
- Tekan Enter

### Menggunakan Cara Internal

Cara internal ini digunakan ketika menyisipkan langsung kode-kode JavaScript ke dalam dokumen HTML. Kode-kode JavaScript dituliskan di dalam elemen `<script> . . . </script>`, seperti contoh berikut ini:

```javascript
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <script>
      console.log("Ini adalah output dari JavaScript");
      console.log("Output ini ditampilkan menggunakan cara Internal");
    </script>
  </body>
</html>
```

### Menggunakan Cara Eksternal

Cara eksternal adalah membuat file mandiri dengan ekstensi **.js** dan memanggil file tersebut sebagai nilai dari atribu `src=" "` dalam elemen `<script>`.

Contohnya saya membuat file baru dengan nama **script.js** yang saya taruh satu lokasi dengan file HTML nya.

![Ilustrasi JavaScript](/images/javascript/pengenalan-javascript-4.png)

Lalu saya isi file **script.js** dengan kode JavaScript seperti berikut ini:

```javascript
console.log("Ini adalah output dari JavaScript");
console.log("Output ini ditampilkan menggunakan cara Eksternal");
```

Lalu file HTML saya ubah bagian elemen `<script>` nya dengan menghapus isinya dan menambahkan atribut `src="script.js"`

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <script src="script.js"></script>
  </body>
</html>
```

Dengan begitu kode JavaScript bisa digunakan untuk lebih dari satu file HTML. Coba lihat hasilnya di Console Browser

![Ilustrasi JavaScript](/images/javascript/pengenalan-javascript-5.png)

Pada praktik-praktik di atas kita sudah berhasil membuat program JavaScript pertama yaitu menampilkan output di Console Browser.

- `console.log( )` digunakan untuk menampilkan informasi ke Console
- Teks yang ditampilkan harus diapit tanda kutip
- Setiap perintah dapat diakiri dengan titik koma (`;`)

## Latihan

1. Buat program yang menampilkan data mahasiswa melalui console browser
2. Buat data diapit menggunakan tanda petik single dan petik double, lalu perhatikan perbedaannya
3. Buat baris kode diakhiri titik koma dan tanpa diakhiri titik koma, lalu perhatikan hasilnya

## Hasil Latihan

1. Program **data mahasiswa**

Edit file **script.js** seperti berikut ini:

```javascript
console.log("=================================");
console.log("DATA MAHASISWA");
console.log("=================================");
console.log("Nama     : Ibnu Ahmad Fauzi");
console.log("Jurusan  : Teknik Informatika");
console.log("Fakultas : Teknologi Informasi");
console.log("NIM      : 19104410027");
console.log("=================================");
```

Hasilnya:

![Ilustrasi JavaScript](/images/javascript/pengenalan-javascript-6.png)

2. Perbedaan diapit petik single dan petik double

Hasilnya sama saja, karena pada dasarnya dengan petik single atau petik double sama-sama mendefinisikan data **String**.

3. Perbedaan diakhiri titikoma dan tidak diakhiri titikoma

Pada JavaScript terbaru kita sudah bisa menggunakan baris pernyataan kode pakai atau tanpa titikkoma, namun alangkah baiknya jika tetap pakai titikkoma.
